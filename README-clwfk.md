# 和田研フォントを、動かす。

**和田研フォントキットのCommon Lisp移植版 CLWFK の実データと実生成処理を使います。** 前の独自8文字サンプル／明朝風レンダラーは使っていません。通常フォントからの骨格抽出も行いません。

## 起動

1. `START.cmd` をダブルクリック。
2. ブラウザで http://127.0.0.1:4184 を開く。
3. 好きな文字を入力。太さ・飾り・書体を変えると原典の生成処理を再実行します。

Node.jsとJavaが必要です。このPCではNode.js 22とJava 17を確認済み。npm installやフォントのOSインストールは不要。起動中のウィンドウを閉じるかCtrl+Cで停止します。起動後の処理はローカルのみで完結します。

## 何を動かしているか

元の `primdata` と `jointdata` → `applykanji` による部品合成 → `normkanji` → **各時刻の `skeleton2list`** → SVG。

元の `mincho.l` / `gothic.l` / `maru.l`、接続・端飾り・曲線の計算を実行します。アニメーションは線幅と明朝の飾りパラメータを変えた60フレームです。表示時に完成パスをモーフしたり、別フォントへ差し替えたりしません。CPUで事前生成してから再生するため、文字変更時には数秒の待ち時間があります。標準再生時間4秒では形状更新は約15回/秒です。

この版の動きは**肉付けの成長**です。画が筆順どおり伸びるアニメーションはまだ実装していません。骨格表示は元の制御点を結ぶ補助線で、正確な筆跡の中心曲線とは限りません。

## 文字の範囲

起動時に読み込む1文字の定義は6,703件。これは読み込まれた定義の件数で、全Unicode対応や全字形の生成成功を保証する数値ではありません。漢字・ひらがな・カタカナ・英数字・記号は、**原典にある範囲**を使用します。ASCII英数字は原典の全角字形に対応付けます。未収録／原典のエラーは画面に表示し、別フォントへ置き換えません。12文字まで入力可能です。

## 原典と互換調整

- 原典配布元：https://www.tanaka.ecc.u-tokyo.ac.jp/ktanaka/Font/
- フォントキットの旧配布元：http://gps.tanaka.ecc.u-tokyo.ac.jp/wadalabfont/
- 使用したCLWFKミラー：https://github.com/nmlgc/efont/tree/69883aef69f4762a9b3afceb257044c71377499d/wadalab-fontkit
- 原典の90ファイルを `engine/clwfk/` に保存。肉付け関数を書き換えていません。
- `engine/prepare.mjs` は、旧EUC-JP処理系とUnicode Lispの違いによる全角英字の大小混同を避けるため、非ASCIIシンボルをエスケープした読み込み用コピーを `engine/compatible/` へ生成します。文字の座標や計算式の変更はありません。
- 上流のビルド手順が呼んでいる未定義の `rm-limit` をアダプターに補いました。合成用の仮想線 `xlimit` / `ylimit` を肉付け対象から除外します。描画される画や点番号は変更しません。
- ゼロの幅や飾りで原典の計算が不定になることを避け、非ゼロフレームでは線幅10%以上、飾り8%以上から開始します。最初のフレームは空です。
- ライセンス本文：`engine/clwfk/README`。著作権表示・条件を維持してください。このアプリは原著作者による公式製品ではありません。

## Unity・移植境界

`engine/clwfk/` は表示環境に依存しないCommon Lispの生成コードです。`engine/bridge.lisp` が時刻・パラメータとデータ変換、`server.mjs` がローカルHTTP、`web/` が表示を担当します。

`POST /api/generate` に `text, style, weight, serif, contrast, steps` を渡すと、骨格と各フレームの輪郭点列がJSONで戻ります。座標は400×400、Y下方向。輪郭点は `angle` が端点、`bezier` 2点＋次の端点が三次曲線です。

`unity/WadalabMotionPreview.cs` は同じ生成エンジンを呼び出し、SceneビューのGizmosで原典の輪郭を表示する接続例です。JSONはUnityに保存してオフライン再生することもできます。UnityのC#だけで生成するネイティブ移植と、塗りつぶしMesh表示は未実装です。前の独自C#レンダラーを和田研フォントの移植版として使わないでください。

## 検証

サーバー起動中に `node --test verify.mjs`。別経路で原典の関数を直接呼んだ結果と最終フレームを比較し、三書体、日本語・英数字、未収録文字、パラメータ端値を検証します。Unityエディター内は未検証です。

## 実行環境の配布

ABCL 1.9.2 は https://abcl.org/ のCommon Lisp処理系です。GPLv2 + Classpath Exception。`runtime/` に実行JAR、対応する公式ソースアーカイブ、ライセンスを同梱します。JavaとNode.js自体は同梱していません。

## 表示UI（更新）

通常画面は白地の文字と左上のⓘだけです。画面をクリックして文字を入力します。ⓘで原典のライセンスが開きます。表示は `maru`、線幅8固定で、変更可能な生成パラメータはHTTP APIに残しています。上記の操作パネル・骨格表示は現在のUIにはありません。

この丸ゴシックはCLWFK原典の字形です。指定された「和田研細丸ゴシック2004」は原典をTrueType化して字形の追加・修正を行った別の配布版です。その追加文字と修正は未導入であり、完全一致・全文字対応は未達です。配布元：https://sourceforge.net/p/jis2004/wiki/index/

`web/preview.html` と `example-animation.json` は以前の明朝サンプルです。現在のUI・丸ゴシックの確認には `START.cmd` から起動する画面を使ってください。
